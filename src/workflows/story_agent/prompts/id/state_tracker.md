Analisis episode cerita ini dan identifikasi status benda/objek penting.

Untuk setiap benda penting (senjata, objek ajaib, alat, dll.), tentukan statusnya:

- "active": Benda ada dan dapat digunakan (berlaku juga jika rusak tapi masih fungsional).
- "lost": Benda hilang, dicuri, atau salah tempat.
- "destroyed": Benda hancur, terbakar, atau hilang permanen.

PENTING:

- Bersikap harfiah. JANGAN tandai benda sebagai "destroyed" jika deskripsinya metafora (cth., "harapannya hancur" atau "server meledak dengan aktivitas").
- Hanya tandai "destroyed" jika objek fisiknya benar-benar hancur.
